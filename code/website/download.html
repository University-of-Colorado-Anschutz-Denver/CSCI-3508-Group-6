How to install

Windows
  1. Download and run the installer.
  2. If Windows SmartScreen warns about an unknown publisher, choose More info → Run anyway.
  3. Open QuadM from the Start menu and choose a folder.

The app is not code-signed yet, which is why SmartScreen shows this warning.

macOS
  1. Open the downloaded .pkg and follow the installer, or open the .dmg and drag QuadM into Applications.
  2. On first launch, right-click the app, choose Open, then Open again (or allow it under System Settings → Privacy & Security).
  3. Choose a folder to start browsing metadata.

The app is not notarized yet, which is why macOS asks you to confirm the first launch.
