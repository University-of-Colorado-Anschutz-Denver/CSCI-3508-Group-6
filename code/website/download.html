Installer (.pkg) Disk image (.dmg)

The .pkg is the graphical installer. The .dmg is the non-graphical option.

Ubuntu / Debian (amd64): download the .deb, then run sudo apt install ./<file>.deb

Builds are made automatically by our CI pipeline and published on GitHub Releases. Checksums (SHA256SUMS.txt) are on the release page.

Install on Windows

  1. Download and run the installer.
  2. If Windows SmartScreen warns about an unknown publisher, choose More info → Run anyway (the app is not code-signed yet).
  3. Open QuadM from the Start menu and choose a folder.

Install on Mac

  1. Open the downloaded .pkg and follow the installer, or open the .dmg and drag QuadM into Applications.
  2. The app is not notarized yet. On first launch, right-click it, choose Open, then Open again (or allow it under System Settings → Privacy & Security).
  3. Choose a folder to start browsing metadata.
