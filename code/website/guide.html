Find a file

Option 1: Manually find the folder

  1. Select the drive you want to navigate in the left-most panel through the top dropdown.
  2. The middle panel will show files and folders contained in the drive. Double-click to open a folder.
  3. Continue navigating through folders until you find your desired file.

You can designate a default drive to open upon launching the app in the Settings menu.

Option 2: Enter the file path

  1. Find or copy the full file path for the file you want to find.
  2. Enter it in the top search bar and hit Enter.
  3. Entering a folder name will show all files in the folder. Entering a file name at the end will show only that file.

View metadata

Single-click a file in the current directory in the center panel. The metadata information will be displayed in the right panel, organized into sections by metadata type.

Edit metadata

Editing existing metadata fields

  1. Once you've selected a file, press the Edit Metadata button at the top of the right panel.
  2. A window will open displaying currently filled fields, as well as common fields for that file type.
  3. Type in your new metadata information in the desired field, then press Save Changes in the bottom right corner. A notice will be displayed if changes were saved successfully or if an error was detected.

Adding custom tags

  1. Once you've selected a file, press the Edit Metadata button at the top of the right panel.
  2. A window will open displaying currently filled fields, as well as common fields for that file type.
  3. Press the + Add Metadata button in the top right corner.
  4. In the first dialog box, type the name of the custom metadata field you would like to add.
    • Not all file types support editing all metadata types. A good rule of thumb is using ID3 for audio files and XMP for other file types.
    • For example, to add a custom field named "Tag 1" with the value "good take", enter XMP:Tag1, press OK, then enter good take and press OK.
  5. Press Save Changes in the bottom right corner. A notice will be displayed if changes were saved successfully or if an error was detected.

Custom field names can only contain letters and numbers with no spaces.

Search via metadata

  1. Navigate to the folder you would like to search in.
  2. In the top bar of the center panel, type in the value you would like to search for among all metadata fields.
  3. When the search is complete, all files in the current folder that have the specified term in any metadata field will be displayed.

Only files in the current folder, not sub-folders, will be displayed.

FAQ

Does the app change my original files?

Yes, but only when you press Save. The only data chnaged is metadata, so your file will still work the same in other applications.

How is new metadata information stored?

Metadata is embedded in all files, and your new tags are stored in the same data chunks as existing metadata.

I've searched for a file in QuadM. How do I use it in another application?

Right-click a file to copy its file path. Then, you can find it in your file explorer and use as normal.

Something is wrong. Where do I report it?

Use the feedback form.
