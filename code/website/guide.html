User guide

Four steps cover everything: open a folder, edit, tag, search. Not installed yet? Download QuadM.

On this page 1. Open a folder 2. Edit metadata 3. Tag files 4. Search by tag Where tags are stored FAQ

1. Open a folder

Click Open folder. The app scans the folder and subfolders and lists supported files.

2. Edit metadata

Select a file. Edit Title, Author or Comments, then press Save. Use the All fields tab to see hidden fields (read-only).

Your file is only changed when you press Save.

3. Tag files

In the Tags box, type a tag and press Enter. Remove a tag with its ×. Tags are written when you Save.

4. Search by tag

Type a tag in the search bar, choose the folder scope, and press Search.

Where tags are stored

FormatTag storage
PNG, JPGEmbedded XMP in the file
MP4, WAV, MP3Sidecar file, e.g. clip.mp4.xmp

Keep the .xmp sidecar next to the media file when you move or copy it.

FAQ

Does the app change my original files?

Only when you press Save.

Do I need to create a database?

No. Tags live in your files; the app rebuilds its search index by scanning.

Something is wrong. Where do I report it?

Use the feedback form.
