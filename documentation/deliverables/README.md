# Final Deliverables

The final submission package has three required deliverable types. Place the two binary files in this folder and keep the plain-text appendix file(s) in `../appendix/`:

1. `final-report.pdf` - comprehensive written project report based on `../05-final-report-template.md`.
2. `project-presentation.pptx` - final PowerPoint based on `../07-presentation-outline.md`.
3. `../appendix/source-code-appendix.txt` (or clearly numbered `.txt` files) - complete plain-text copies of all application and test source code.

Submit all three deliverable types together. Before submission, open the PDF and PowerPoint on another computer if possible and verify that fonts, diagrams, media, links, and page/slide formatting work. Keep drafts elsewhere under `documentation/` and only the final versions in this folder.
