# Design Assets

Store editable diagram sources and readable exports used by `../03-system-design.md` in this folder. Suggested names include `architecture`, `use-case`, `class-diagram`, `sequence-[scenario]`, and `data-schema` with the appropriate file extensions.

For each diagram:

- Keep an editable source format when the selected tool supports one.
- Export a readable image or PDF that can be opened without the original tool.
- Link the exported version from `../03-system-design.md` using a relative path.
- Use the same component, class, entity, and interface names found in the report and code.
- Do not include tool caches, temporary files, or account credentials.
