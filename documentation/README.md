## Documentation Standards

- Use clear headings, numbered requirements, labeled figures, and labeled tables.
- Give every diagram a title and explain it in the surrounding text.
- Cite all external ideas, text, images, libraries, and data using one consistent citation style.
- Keep requirements, design, implementation, and tests consistent with one another.
- Record meaningful changes in Git with descriptive commit messages.
- Replace placeholders and remove template instructions before submission.

## Finalization Workflow

1. Complete and proofread the Markdown templates.
2. Transfer or convert the final report into a polished document.
3. Export the report to `deliverables/final-report.pdf`.
4. Build the presentation and save it as `deliverables/project-presentation.pptx`.
5. Follow `appendix/README.md` to copy all application and test source code into one or more plain-text appendix files.
6. Open the PDF and PowerPoint to confirm that text, diagrams, and formatting display correctly.
7. Complete `08-rubric-checklist.md` as a team.
