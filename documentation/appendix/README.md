# Source Code Appendix

The assignment requires all application and test source code in plain-text appendix files. Keep the original runnable files in `../../code/` and `../../tests/`, then copy each source file's complete contents into `source-code-appendix.txt` or the numbered files below.

If one text file becomes difficult to review, use numbered files such as:

- `source-code-appendix-01.txt`
- `source-code-appendix-02.txt`
- `source-code-appendix-03.txt`

For every source file, include a visible separator with its original relative path, language, and purpose. Include application code, test code, scripts, migrations or schema code, and source configuration templates. Do not include dependencies, build output, binary artifacts, passwords, tokens, or other secrets.

Confirm that the appendix matches the final submitted versions in `../../code/` and `../../tests/`. Use the file separators as a manifest to verify that no application or test source file is missing.
