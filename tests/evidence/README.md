# Test Evidence

Store selected, non-sensitive evidence that supports the test report, such as screenshots, small result exports, and curated log excerpts saved as Markdown or `.txt`. Use descriptive names that include the test ID and date, for example `TC-01-2026-10-15.png`.

Do not commit secrets, private user data, large generated reports, raw environment logs, or redundant evidence. Link each retained artifact from `../test-cases.md` or `../../documentation/04-testing-report.md`.
